# LS-Materialien

Begleitmaterial zu den Lernsituationen der Umwelttechnolog(inn)en am Hans-Schwier-Berufskolleg Gelsenkirchen (Fachbereich Umweltschutztechnik).

Statische Seiten ohne Build-Schritt und ohne externe Abhängigkeiten (Schriften eingebettet, kein JavaScript nötig) – laufen auf GitHub Pages, offline und in der IServ-Dateiansicht.

| Pfad | Inhalt |
|---|---|
| `index.html` | Startseite mit allen Materialien |
| `abwasser/ls-4-1/hilfekarten.html` | Hilfekarten zu den Übungsaufgaben LS 4.1 (Sammelbecken PW Bahnhofstraße) |
| `abfall/sickerwasser-sammelbecken/hilfekarten.html` | Hilfekarten zu den Übungsaufgaben Sickerwasser-Sammelbecken SB-1 |

Einzelne Aufgaben sind direkt verlinkbar, z. B. `…/hilfekarten.html#S2`; Stufen über `#stufe-B`, `#stufe-S`, `#stufe-V`.

## GitHub Pages
*Settings → Pages → Deploy from a branch → `main` / `(root)`* – danach erreichbar unter `https://mein-hsbk.github.io/LS-Materialien/`.
